# TDDワークフロー スキル

テスト駆動開発（TDD）のRed-Green-Refactorサイクルに従って、安全かつ品質の高いコードを実装します。

## 前提条件

- テストフレームワークがプロジェクトに導入されていること
- テスト実行コマンドが設定されていること

## 手順

### ステップ 1: 要件の理解 🔍

1. 実装する機能の要件を確認する
2. テストケースの一覧を洗い出す
3. テストの優先順位を決める（基本ケース → エッジケース → エラーケース）

### ステップ 2: Red（テストを書く）🔴

1. 最初のテストケースを実装する
2. テストを実行し、**失敗すること**を確認する
3. テストがコンパイルエラーではなくアサーションエラーで失敗することを確認する

```
# テスト実行コマンド例
npm test           # JavaScript/TypeScript
pytest             # Python
go test ./...      # Go
mvn test           # Java
```

### ステップ 3: Green（最小限の実装）🟢

1. テストをパスするための**最小限のコード**を実装する
2. テストを実行し、**成功すること**を確認する
3. この段階では美しいコードである必要はない

### ステップ 4: Refactor（リファクタリング）🔵

1. テストがパスした状態で、コードを改善する
2. 重複の除去、命名の改善、構造の整理
3. リファクタリング後もテストがパスすることを確認する

### ステップ 5: 繰り返し 🔄

ステップ2〜4を残りのテストケースに対して繰り返す

## チェックリスト

- [ ] すべてのテストケースが実装されている
- [ ] すべてのテストがパスしている
- [ ] エッジケースがカバーされている
- [ ] エラーケースがカバーされている
- [ ] コードがリファクタリングされている
- [ ] テストカバレッジが十分である
