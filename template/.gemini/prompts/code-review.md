# コードレビュー依頼プロンプト

## 目的
指定したコードのコードレビューを実施し、改善点を提案する。

## 使い方
以下のプロンプトをコピーして、プレースホルダーを実際の値に置き換えてください。

---

## プロンプト

```
以下のコードをレビューしてください。

**対象ファイル**: {ファイルパスまたは@ファイル参照}
**レビュー観点**:
- コードの可読性
- パフォーマンス
- セキュリティ
- テストカバレッジ
- エラーハンドリング

**特に注意してほしい点**: {特に注目してほしい箇所があれば記述}

レビュー結果は以下のフォーマットで出力してください：

1. **重大度** (Critical / Warning / Info)
2. **対象箇所** (ファイル名:行番号)
3. **指摘内容**
4. **改善案** (コード例付き)
```

---

## 出力例

| 重大度 | 対象箇所 | 指摘内容 | 改善案 |
|--------|----------|----------|--------|
| Critical | auth.ts:45 | SQLインジェクションの脆弱性 | パラメータバインドを使用 |
| Warning | utils.ts:12 | 未使用のインポート | 削除を推奨 |
