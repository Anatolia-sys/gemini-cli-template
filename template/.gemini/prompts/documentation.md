# ドキュメント生成プロンプト

## 目的
コードやプロジェクトに関するドキュメントを自動生成する。

## 使い方
以下のプロンプトをコピーして、プレースホルダーを実際の値に置き換えてください。

---

## プロンプト

```
以下のドキュメントを生成してください。

**ドキュメントの種類**:
{以下から選択}
- [ ] API仕様書（エンドポイント一覧）
- [ ] 関数・クラスのJSDoc / docstring
- [ ] README.md
- [ ] 設計ドキュメント
- [ ] 変更履歴（CHANGELOG）
- [ ] その他: {自由記述}

**対象**: {ファイルパス、ディレクトリ、または@ファイル参照}

**出力フォーマット**: Markdown

**含めてほしい内容**:
- 概要
- 使い方（Usage）
- パラメータ / 引数の説明
- 戻り値の説明
- 使用例（コードサンプル）
- 注意事項

**対象読者**: {開発チーム / 外部ユーザー / 新人エンジニア}
```

---

## 補足

- 大量のファイルに対してドキュメントを生成する場合は、ディレクトリ単位で指定してください
- 既存のドキュメントがある場合は `@既存ドキュメント.md` で参照し、整合性を保つよう指示してください
