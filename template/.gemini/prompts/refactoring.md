# リファクタリング指示プロンプト

## 目的
指定したコードのリファクタリングを依頼する。

## 使い方
以下のプロンプトをコピーして、プレースホルダーを実際の値に置き換えてください。

---

## プロンプト

```
以下のコードをリファクタリングしてください。

**対象ファイル**: {ファイルパスまたは@ファイル参照}

**リファクタリングの目的**:
{以下から該当するものを選択または自由記述}
- [ ] 可読性の向上
- [ ] パフォーマンスの改善
- [ ] 重複コードの削除（DRY原則）
- [ ] 単一責任の原則（SRP）への準拠
- [ ] テスタビリティの向上
- [ ] その他: {自由記述}

**制約条件**:
- 外部インターフェース（API、引数、戻り値）は変更しない
- 既存のテストがすべてパスすること
- {追加の制約があれば記述}

**手順**:
1. まず現在のコードを分析し、問題点を列挙してください
2. リファクタリング計画を提示してください
3. 承認後、実装してください
4. 変更前後の比較を提示してください
```
